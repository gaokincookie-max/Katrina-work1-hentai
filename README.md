# 家庭科 確認テスト 強化版

教科書範囲をもとにしたブラウザ確認テストです。

## 問題数
- 通常モード: 251問
- 変態モード: 61問
- 合計: 312問

## モード
- **通常モード**: 基本〜標準。穴埋め・選択・○×・計算。
- **変態モード**: マイナーな箇所、似た用語の細かい区別、逆引き、複合問題、ひっかけ中心。
- **混合モード**: 両方から出題。

## 機能
- 単元選択
- 出題形式の絞り込み
- 10 / 20 / 30 / 50 / 100 / 150 / 200 / 全問
- ランダム / 範囲順
- 選択・○×は押した瞬間に採点
- 穴埋め・計算は未回答提出可能
- 解説・教科書ページ表示
- 間違えた問題だけ再挑戦
